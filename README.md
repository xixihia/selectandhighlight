# Select and Highlight

A modern VS Code extension that lets you select text and highlight it — just like a PDF reader or Word — with persistent multi-color markers that stay even after you close and reopen VS Code.

Perfect for reading code, annotating long files, studying, and marking TODO areas.

## Highlight selected text in 3 colors:
	•	Yellow → Cmd+Shift+H
	•	Green → Cmd+Shift+G
	•	Blue → Cmd+Shift+B

## Clear all highlights instantly
Cmd+Shift+U

## Highlights do NOT modify your file
Stored separately — clean and safe.

## Persistent highlights
Your highlights are saved and automatically restored when you reopen the file or restart VS Code.
